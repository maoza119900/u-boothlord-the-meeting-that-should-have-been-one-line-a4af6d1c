One sentence that could have replaced an entire pointless meeting:

> We just held an hour-long meeting to agree that we need another meeting.

The entry is 72 characters long (one sentence; the file adds a single
trailing newline, 73 bytes total), well inside the gate of 1–200 characters.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). The program is deterministic: it writes one
fixed sentence, reads no clock, randomness, network or files, so every run
produces byte-identical output.
